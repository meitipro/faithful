---
title: Glossaries
description: Required renderings per language, terms that stay as written, and what the judge sees.
---

A glossary maps a source term to how it must appear in each target language. It is set when the program opens and is
the same for every section.

```json
{
  "recovery phrase": { "fa": "عبارت بازیابی", "es": "frase de recuperación" },
  "validator": { "de": "keep" },
  "Intelligent Contract": "keep"
}
```

- A term mapped to `"keep"` stays exactly as written in every target language.
- A term mapped to an object gives a rendering, or `"keep"`, per language. A language with no entry has no rule for
  that term.
- At most 40 terms; each term and rendering at most 60 characters, one line. Terms are unique ignoring case, and a
  rendering may only name the program's own target languages.

## What the judge sees

Only the terms that appear in the section's source, compared ignoring case, with the rendering for the target
language. Every term and rendering is fenced like the texts, so a glossary entry cannot close its block. The editor
shows the same list under "Glossary in this section".

A wrong glossary term is one of the problems the rubric names, so a localised term the glossary says to keep comes
back FLAWED.

## Inflection

Languages inflect nouns: German pluralises *Validator* as *Validatoren*, Turkish adds *-lar*, Portuguese turns *frase*
into *frases*. On the first two contracts a kept *validator* written as *Validatoren* was judged FLAWED, which a
German reader would not call wrong. Recognising an ending is something code can do, so the contract now does it:
for every term to keep, it looks for the term at the start of a word in the translation, ignoring case, takes any
ending the word carries, and tells the judge what it found, as a checked fact. Renderings say that inflected forms
are fine. For a German section:

```text
validator -> validator (keep untranslated; endings the target grammar adds to it are fine; checked by code: found in the translation with an ending the target grammar adds: Validatoren)
recovery phrase -> Wiederherstellungsphrase (inflected forms of this rendering are fine)
```

A kept term that was translated away reads `checked by code: not found in the translation`, so it still comes back
FLAWED. The [evaluation](/docs/more/evaluation) has both: the German case, now FAITHFUL, and a Spanish
*Contrato Inteligente* for a kept *Intelligent Contract*, still FLAWED; the multilingual set adds a Turkish suffix on a
kept term and a Portuguese plural of a rendering.

## Style and tone

Faithful judges meaning and readability, not house style. A project with strong tone rules can state required
renderings for its key terms; anything else is a style choice, and style choices that keep the meaning are accepted.
