## How validators agree

The leader asks its model and returns two strings: the verdict and the reason. Each validator asks its own model the same prompt and agrees only when its own **verdict** (FAITHFUL, FLAWED or WRONG_LANGUAGE) is the leader's. The reason is stored from the leader's answer for the translator to read and is never compared.

An answer that cannot be read (not JSON, or a verdict outside the three labels) is retried once, then fails the round. It never becomes a verdict. Spellings such as `WRONG LANGUAGE` or `wrong-language` read as the label.

## What the prompt never sees

Attempts, claims, rates, the pool and the exact checks are the contract's business. The prompt does not mention them, and a test fails if it starts to: a translation is judged on what it says, never on what it would cost.
