# Silent demo, about 90 seconds

No voice. Every screen says what is happening; consensus waits are cut short with the transaction link left on
screen. Everything shown is on the live site, read from the chain.

| Time | Screen | What the viewer sees |
|---|---|---|
| 0:00 | Landing `/` | The promise, and a real English and Persian pair from program 2 with its FAITHFUL verdict, the GEN credited and the judge transaction |
| 0:08 | Start a program `/new` | Paste a docs file: it splits into sections with their lengths; pick Persian, Spanish and German; add a glossary term; set 12 GEN and fund |
| 0:25 | Editor `/s/<id>/fa`, translator wallet | Claim for 48 hours; type a translation with a changed number: the Numbers check turns red with "number … is missing"; fix it in Persian digits; every check turns blue; Submit for checking |
| 0:45 | Editor | "Validators are comparing the texts" with the transaction link, then FAITHFUL, 12 GEN credited |
| 1:00 | Another section | A softened warning comes back FLAWED with the problem named; the revision comes back FAITHFUL (program 2, section 15 in Persian holds exactly this history) |
| 1:20 | Export `/export/2/fa` | The Persian export as Markdown, each section linked to the transaction that judged it |

Before recording, open a fresh program from `/new`: program 2's open cells are for reviewers, and a recording
should not take them.
